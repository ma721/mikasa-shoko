# 三笠商行 サイト

Cloudflare Pages で公開しているサイト。GitHubにpushすると自動デプロイされる。

## ファイル構成

```
index.html              トップページ（会社紹介＋2系統への分岐）
kin/index.html          菌シリーズLP
medaka/index.html       メダカ用品LP
old-index.html          旧トップページ（残してある）
assets/
├── labels/             菌ラベル画像3枚
└── medaka/             メダカ商品画像
```

ビルドツールなし。素のHTML+CSSのみ。JSも不使用。

## Cloudflare Pages 設定

- フレームワークプリセット: None
- ビルドコマンド: なし（空欄）
- 出力ディレクトリ: /

## デザインの決まりごと

コンセプトは「上海洋行風レトロ」。真鍮ゴールドの二重枠・明朝の縦看板が共通の骨格。
ページごとにベースの色を変えている。

| ページ | ベース色 |
|---|---|
| トップ | 深緑 `#16332C` |
| 菌シリーズ | 深緑 `#16332C` |
| メダカ用品 | 水の藍 `#123A55` |

共通の色
- ゴールド `--gold #B08A3E` / `--gold-lt #CBA968` / `--gold-dk #8A6A2A`
- 生成り `--paper #F5EFE1` / `--paper-2 #EFE7D4`
- 朱印 `--seal #9E3B2E`

フォント（Google Fonts）
- 見出し・和文装飾: Shippori Mincho B1
- 本文: Zen Kaku Gothic New
- 欧文: Cormorant Garamond（斜体で使う）

### 縦書きについて

`writing-mode` を使うと環境によって文字が重なって崩れる。縦の看板は1文字ずつ `<span>` を縦に積むflex方式で組んである。同じ処理をするときは同じ手法で。

## 文言についての制約（重要）

菌シリーズのページは薬機法・景品表示法に配慮した内容にしてある。以下は意図的に書いていないので、勝手に足さないこと。

- 免疫力、病気の予防・軽減、風邪・感染症に関する表現
- 「野菜が甘くなる」「肉・卵の品質が向上する」などの断定的な効果
- 輸入・海外調達を匂わせる表現（菌は輸入品ではない）

「16種類のアミノ酸・ビタミン類を含む」は成分事実なのでOK。

## 商品情報（変更しないこと）

菌の希釈率
- 基本ブレンド: 善玉菌2 : 乳酸菌1 : 光合成細菌1
- ペット・動物 → 100倍希釈
- 植物 → 1000倍希釈
- 空間・消臭（霧吹き）→ 50倍希釈
- お部屋（加湿器）→ 100倍希釈
